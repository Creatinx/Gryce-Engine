## 2. 核心运行时（GryceCore.dll）

### 2.1 ECS

- `ecs::World`：系统注册/调度、场景挂载（`attach_scene`）、更新开关（Play Mode 用）；
- `ecs::ComponentStore`：组件存储与遍历；
- `ecs::Query` / `foreach_with_components`：多组件遍历查询；
- 内置系统：
  - `AnimatorSystem` — 骨骼动画驱动（`GCore_Init` 注册）；
  - `FractureSystem` — 可破坏体碎裂（`GCore_Init` 注册）；
  - `SubViewportSystem` — 3D→2D 运行时视口（`GCore_Init` 注册）；
  - `PhysicsSystem3D` / `PhysicsSystem2D` — Play Mode 物理模拟（`GPhysics_AttachSystems` 注册，位于 GrycePhysics.dll）；
  - `RenderSystem2D` / `RenderSystem3D` — 渲染（位于 GryceRenderer.dll）。

### 2.2 场景 / 实体

- `scene::Scene` / `scene::Entity`：节点层级（唯一合成根）、父链变换、`foreach` 遍历、按名查找；
- UUID 实体标识 + `EntityHandleMap`（对外句柄 ↔ 内部 UUID 映射，场景重建时重建）；
- `.gesc` JSON 场景序列化：版本 2，兼容 v1；`res:/` 虚拟路径；差异保存、场景热重载（demo 按文件时间戳自动重载）；
- Prefab / Prefab Variant：嵌套、覆盖参数、还原模板、Apply/Revert、`PrefabInstance` 组件；
- Play Mode：进入播放前保存场景 JSON 快照，停止时恢复（丢弃播放期间的物理/动画/编辑改动）；
- 屏幕拾取 / 世界射线拾取（MeshRenderer、SkinnedMeshRenderer 世界 AABB 求交）。

### 2.3 反射

- `reflection::Registry` + `register_builtin_reflections()`：组件字段反射（名称、类型、读写回调、只读标记）；
- `ComponentFactory`：按名称注册/创建组件（含类型描述，编辑器 Create Entity 对话框使用）。

### 2.4 资源（`assets/`、`resources/`）

| 能力 | 说明 |
|---|---|
| `AssetManager` | mesh / texture / material 缓存，引用计数 + LRU 卸载 |
| `AsyncLoader` | 线程池异步加载 |
| `.gpack` / `.gpkg` | 资源包挂载（`gpack_bundle`）；`GCore_Init` 自动挂载项目根下所有包，`AssetManager::resolve_for_reading` 统一解析（真实文件优先、包内提取兜底） |
| 模型 | OBJ 内置加载器 + Assimp（FBX / glTF / DAE / PLY / STL，`GRYCE_HAS_ASSIMP` 条件编译） |
| 纹理 | PNG / JPG / BMP（stb_image）、DDS（BC1~BC7）、KTX（ASTC / ETC2）、HDR/EXR（tinyexr）、立方体贴图、压缩纹理 |
| 字体 | TTF 动态图集（stb_truetype → `FontAtlas`） |
| 材质资源 | `.gmat` 加载/保存；`.gimport` 导入设置 |
| 路径 | `res:/` 虚拟路径 → `Project::root`；统一 UTF-8，支持中文文件名 |

### 2.5 音频（`audio/`）

- `AudioEngine`（miniaudio 实现）：播放/暂停/停止、音量、循环、3D 定位；
- `AudioSource` / `AudioListener` 组件；
- `TimeStretcher` 变速器；
- 注：音频源码位于 GryceCore.dll（`GryceAudio.dll` 拆分列为 TODO）。

### 2.6 数学 / 工具

- `math/`：Vector2/3/4、Matrix4、Quaternion、Ray、相机（透视）、插值、颜色；
- `utils/`：异步日志 `AsyncLogger`（`GLog` 宏、`MemoryLogSink` 供编辑器 Console）、帧率限制器 `FrameLimiter`、截图请求。

## 3. 渲染（GryceRenderer.dll + core/render）

### 3.1 RHI 抽象

- `render::IRenderBackend` 接口：buffer / texture / framebuffer / shader / 命令队列 / 截图 / 帧控制；
- `RenderContext`：后端无关渲染上下文，支持异步渲染线程（命令队列）与同步模式；
- 后端实现：
  - **OpenGL 4.6**（`render/opengl/`）：GL 后端、缓冲、着色器、纹理、帧缓冲、帧节奏（`WGL_NV_delay_before_swap`）、ImGui 后端；
  - **Vulkan 1.2**（`render/vulkan/`）：实例/设备/交换链/缓冲/网格/着色器/纹理/帧缓冲/2D 渲染器/ImGui 后端/VMA。

### 3.2 3D 渲染

- `RenderPipeline`：PBR 正向渲染；
- 材质：albedo / normal / roughness / metallic / ao / emissive（颜色 + 贴图槽 + use 开关）、UV 缩放/偏移、透明度、混合模式、双面；
- 高级材质（扩展 BRDF）：Clearcoat（车漆/塑料，独立清漆层）、Sheen（织物，D_Charlie）、各向异性 GGX（金属拉丝/CD 纹路，T/B 旋转可调）；
- 光照：最多 8 盏灯（方向光 / 点光源 / 聚光灯），多光源按亮度/距离优先级排序；
- 点/聚光衰减：物理正确的 inverse-square 衰减 + 平滑截止（不再使用线性衰减）；
- 阴影（CSM 级联阴影）：
  - 1~4 级级联（默认 3），practical split scheme（线性/对数按 lambda 插值），每级独立分辨率与 bias；
  - Slope-Scaled Depth Bias（按入射角动态调整）+ Normal Offset Shadow Mapping（顶点阶段沿法线推几何）；
  - Texel Snapping（阴影盒对齐纹素网格，消除相机移动抖动）；
  - Cascade Blend（级联边界 10-20% 交叉淡入淡出）；
  - 16-tap 旋转 Poisson PCF 软阴影，可选 PCSS（遮挡搜索 → 半影估计 → 动态半径 PCF）；
  - 接触阴影（Contact Shadow）：基于屏幕空间深度的近距离接触阴影，消除
    Peter-Panning（物体悬浮阴影）；strength / radius / steps 可调；
    着色器单一来源在 `examples/common/shaders/`（GL 后端含 `.vert` + `.frag`）；
- IBL：环境光照、天空盒、HDR/EXR 环境贴图、`IBLGenerator`；
- 后处理栈（HDR 帧缓冲 → Bloom → tonemapping → 调色 → 镜头效果）：
  - Bloom：阈值提取 → 5 级降采样高斯模糊 → 上采样合成（半分辨率），阈值/强度可调；
  - tonemapping：Reinhard / ACES / AgX / 参数化 Filmic（白点/黑点/对比度）；
  - EV100 摄影曝光 + 手动曝光；
  - Lift/Gamma/Gain + 阴影/中间调/高光调色（DaVinci 风格）、饱和度；
  - 轻量镜头效果：胶片颗粒、暗角、色差（Chromatic Aberration）；
  - 有序抖动（Bayer 4x4）消色带；
  - 3D LUT 色彩分级（1024x32 打包贴图，三线性采样，强度可调）；
  - 自动曝光（GPU 亮度反馈链：HDR → 6 级亮度降采样 → 1x1 → 双缓冲曝光更新，目标亮度/范围/速度可调）；
  - TAA v1（半像素 Halton 抖动 + 历史帧 + 邻域钳制；暂无运动矢量重投影）；
  - 屏幕空间环境光遮蔽（GTAO-lite 地平线搜索 + 深度感知双边上模糊，半分辨率）；
  - 物理光照单位：点/聚光 lumen→candela(÷4π)，方向光按 lux 直传（配合 EV100 曝光使用）；
- HDR 分析视图：Albedo / Normal / Roughness / Metallic / Shadow / Direct / Indirect / Cascade 可视化；
- 骨骼蒙皮：GPU skinning（128 骨上限），GL/VK 双后端。

### 3.3 2D 渲染

- `Renderer2D` 批处理器（矩形/纹理/文字/圆形/多边形/光照）；
- `render2d` 高层 API：视口、相机、精灵、Tilemap、粒子、视差、光照（环境光/方向光/点光源/聚光灯/法线贴图/阴影遮挡）；
- `Skybox2D`、`SubViewport`（3D→2D 纹理注入）。

### 3.4 UI 集成

- ImGui（`third_party/imgui`）+ ImGuizmo（`third_party/imguizmo`）源码随包；
- `ImGuiRenderer` 与 GL/VK 双后端 ImGui 通道。

## 7. 编辑器（WPF，C#）

### 7.1 技术栈

- `.NET Framework 4.8`、WPF、x64；
- iNKORE.UI.WPF.Modern（Fluent 风格）主题；
- 仅通过 P/Invoke 调用 4 个原生 DLL 的 C API（`editor/src/Native/` 与头文件一一对应）；
- 渲染集成：`ViewportHwndHost` 提供 HWND → `GWindow_InitExternal` → `GRender_Init(OpenGL, sync_mode)` → 专用渲染线程逐帧驱动；
- 构建：CMake 自定义目标 `GryceEditor`（`dotnet build`，与 generator 无关），核心 DLL 由
  `gryce_copy_dll_to_editor` 自动部署到 `editor/bin/<Config>/net48/`（csproj 固定 OutputPath，不依赖 VS 解决方案）。

### 7.2 面板与功能

| 面板 | 功能 |
|---|---|
| Hierarchy | 实体树（层级、重命名、重挂、删除、复制/粘贴、导出/导入 JSON） |
| Inspector | 反射字段编辑（Transform、组件属性）、材质 PBR 参数/贴图槽/AO/自发光/UV、动画编辑器入口 |
| Viewport | 场景视图（内嵌 GL 窗口、相机控制、Gizmo 拖动、拾取） |
| GameView | 游戏视图（当前与 SceneView 共用管线） |
| Project | 资源树（文件夹、场景/模型/纹理/材质文件） |
| Console | 引擎日志（`GOnLogMessage` 回调转发） |
| Animation | 动画面板（片段/播放/循环/速度/时间轴）+ 动画编辑器（骨骼树、轨道关键帧、导出 .anim.json） |
| Toolbar | Play / Pause / Step、渲染后端显示、VSync 开关 |

### 7.3 编辑器特性

- Play Mode：快照保存/恢复，物理与动画真实模拟；
- 材质编辑器：PBR 参数 + 6 张贴图槽 + AO/自发光/UV 缩放与偏移，修改即时生效，支持加载 `.gmat`；
- 动画 / 骨骼动画编辑器：片段列表、播放控制、骨骼层级树、骨骼轨道 P/R/S 关键帧表格、关键帧 JSON 导出
  （核心新增 `GAnimator_GetBone*` / `GAnimator_GetClipTrack*` / `GAnimator_GetClipKeyframe*` 查询 API）；
- 脚本编辑器（Monaco）：undo/redo 转发（Ctrl+Z/Y/Shift+Z、工具栏按钮），未保存脏标记（标签前 `*`）与离开/换文件时的保存确认；
- Godot 风格 Create Entity / Add Component 对话框（搜索、最近、分类、描述）；
- Gizmo：平移/旋转/缩放（`W/E/R` 切换、本地/世界空间）；
- 快捷键：`Ctrl+S/Z/Y/N`、`Delete`、`F2`（重命名）、`F`（聚焦）、`W/E/R`、`Ctrl+P`、`Ctrl+X/C/V/D`
  （视口原生窗口聚焦时同样生效）；
- 主题（深色/浅色）与中/英本地化运行时切换，持久化到 `editor_settings.json`；
- 自动保存（间隔可配置，Play 期间暂停；gizmo 拖拽/输入进行中自动推迟）；
- 场景修改脏标记与保存提示：新建/加载场景、切换项目、关闭窗口前统一确认（播放中也会先停止再询问）；
- 操作逻辑修复：复制/粘贴/实例化 Prefab 的 Undo 可完整恢复、快速连续创建实体的 Undo 句柄按序绑定、
  2D 编辑器临时相机不再被保存进场景、模型导入排队、重命名统一可撤销、材质拖放作用于目标实体；
- 窗口尺寸自适应（DPI）、Mica 效果（Win11）。

### 8.2 2dDemo（2D 平台跳跃，Lua 玩法 + 场景驱动）

重做后的 2dDemo 把**关卡内容放在编辑器可加载的 `.gesc` 场景里，玩法逻辑 100% 写在
GryceSRT Lua 脚本中**（`scripts/*.lua`），游戏入口只是一个 C-API 宿主：

- **关卡系统**：`scenes/level_1~3.gesc` 三个关卡 + `levels.json`（关卡顺序、每关昼夜起始
  相位、重力、敌速）；`goal.lua` 抵达终点旗帜过关，`game_manager.lua` 切换下一关，全部通关
  后显示胜利；
- **编辑器可加载**：Tilemap、玩家、敌人、金币、枪械升级、尖刺、终点、灯光、视差、音效、
  HUD、GameManager 都是场景实体，可在 WPF 编辑器中打开/摆放/保存（生成器
  `tools/gen_2dDemo_levels.py`）；编辑器 Play 模式与独立 exe 跑同一套 Lua 逻辑；
- **Lua 玩法脚本**：`player.lua`（移动/跳跃/瞄准/射击/受伤/重生）、`enemy.lua`（巡逻）、
  `bullet.lua`（飞行/命中）、`coin.lua` / `powerup.lua`（拾取）、`goal.lua`（过关判定）、
  `camera.lua`（跟随）、`game_manager.lua`（HUD/昼夜/关卡流程）、`common.lua`（公共库）；
- **光照**：2D 方向光/点光源/聚光（玩家手电筒跟随鼠标）+ 环境光 + 阴影；
- **白昼/夜晚**：120 秒昼夜循环，白天→黄昏→夜晚→黎明调色板由脚本实时插值环境光、天空、
  方向光与视差色调（每关从不同相位开始：白天/黄昏/午夜）；
- **物理**：Box2D 刚体/碰撞体/重力（每关可配，`engine.physics.set_gravity`），踩踏敌人反弹、
  掉落/尖刺伤害；
- **敌人**：按 `PatrolLeft_EnemyN` / `PatrolRight_EnemyN` 标记巡逻，可踩踏、可射击；
- **枪械**：鼠标/`Z` 瞄准射击（子弹带光源 + 枪口火光），拾取 `PowerUp` 升级为三发散射；
- **过关条件**：抵达终点旗帜（+100 分 + 金币奖励）→ 下一关 / 通关。

> 同时是完整的 **GryceGC-A 项目**（`project_settings.json` 主场景 `scenes/level_1.gesc`），
> 可直接用 `grycegc` 打包成独立游戏；打包产物的 GryceGame 模板同样同步输入并运行同一套 Lua
> 玩法（标准见 [GryceGC-A](./GryceGC-A.md)）。

## 10. 工具与自动化

| 工具 | 说明 |
|---|---|
| `build.py` | 一键构建：编译器锁定（MinGW/MSVC/Clang，`--compiler`）、依赖下载、Ninja generator、清理、可选 WPF Editor（dotnet）。纯 CMake 流程，不生成 VS 解决方案 |
| `tools/deps_manager.py` | 下载/解压外部依赖（GLFW/GLEW/Assimp/Box2D/Jolt/GoogleTest），支持镜像与离线缓存 |
| `tools/grycegc/`（C++，构建产物 `grycegc.exe`） | GryceSPC 打包（GryceGC-A 标准，见 [GryceGC-A](./GryceGC-A.md)）：将 res:// 内容按类别打包为多个 `.gpkg`（GPAK 格式，经 GryceCore 的 GPack C API 生成），输出 `exe + runtime/（DLL）+ assets/*.gpkg + gdata`（源文件记录 + 64 字节 SHA-512 密钥 + 作者），不再复制 res/ 目录；游戏入口延迟加载 runtime/ 的 DLL，Core 自动挂载 assets/ 下的包 |
| `tools/gen_skybox.py` | 天空盒纹理生成 |
| `tools/gen_skinned_fixture.py` | 骨骼动画测试模型生成 |
| CMake 集成 | Vulkan 着色器自动编译（SPIR-V，`cmake/shaders.cmake`）、编辑器 DLL 自动部署（`gryce_copy_dll_to_editor`） |
