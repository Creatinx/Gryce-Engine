# Gryce Engine 核心模块代码解析

> 本文档深入分析每个核心模块的内部实现，帮助开发者理解代码入口、关键类和数据结构。

---

## 1. 引擎生命周期与运行时上下文

### 1.1 入口点：`core/api/core_api.cpp`

引擎全局状态定义在 `gryce_core::g_core_state`（类型 `EngineContext`），包含：

```cpp
struct EngineContext {
    bool initialized;
    std::unique_ptr<ecs::World> world;          // ECS 世界
    CommandBuffer cmdbuf;                       // 命令缓冲（双缓冲 8192×2）
    EntityHandleMap entity_map;                 // 实体句柄↔UUID 映射
    CallbackTable callbacks;                    // 编辑器回调函数表
    bool play_mode, paused;                     // Play Mode 状态
    std::string play_snapshot_json;             // Play Mode 快照
    GEntityHandle selected_entity;
    int scene_mode;                             // 0=2D, 1=3D
    std::unique_ptr<Scene> scene_slot_2d, scene_slot_3d; // 双场景槽
    InputState input;                           // 输入状态
};
```

**初始化流程**（`GCore_Init`）：
1. 创建 `ecs::World`
2. 扫描项目根挂载 `.gpkg`/.`gpack` 资源包
3. 读取 `project_settings.json` 设置主场景路径
4. 注册内置组件到 `ComponentFactory`
5. 注册内置反射到 `reflection::Registry`
6. 注册 `AnimatorSystem`、`FractureSystem`、`SubViewportSystem`、`ScriptSystem`
7. 创建默认 "Untitled" 场景

**每帧循环**（`GCore_BeginFrame` + `GCore_EndFrame`）：
1. `BeginFrame`：swap 命令缓冲双缓冲、消费≤30 条命令、Play Mode 下 `world.update(dt)`
2. `EndFrame`：转发日志、触发延迟回调（`OnSceneLoaded`、`OnEntityListChanged`）

### 1.2 头文件：`core/runtime/engine_context.h`

关键结构体：
- `EngineContext` — 全局运行时状态
- `CallbackTable` — 回调函数指针表
- `InputState` — 输入状态（按键、鼠标位置、增量）
- `InputEvent` — 输入事件（脚本 `_input` 处理用）
- `InputEventKinds` — 事件类型常量（`INPUT_EVENT_KEY_DOWN` 等）

## 2. ECS 核心

### 2.1 World：`core/ecs/world.h` / `world.cpp`

`World` 持有 `Scene` 和一组 `ISystem`，按阶段驱动：

```cpp
class World {
    std::unique_ptr<scene::Scene> scene_;
    std::vector<std::unique_ptr<ISystem>> systems_;
    bool updates_enabled_ = true;
public:
    void attach_scene(std::unique_ptr<Scene>);  // 挂载场景（自动 init）
    std::unique_ptr<Scene> detach_scene();       // 卸载场景
    void register_system(std::unique_ptr<ISystem>);
    void init();     // 场景初始化 + 所有系统 on_init
    void update(float dt);  // Play Mode 下调用所有系统 on_update
    void render(RenderContext& ctx);  // 调用所有系统 on_render
};
```

### 2.2 ISystem 接口：`core/ecs/system.h`

```cpp
class ISystem {
    bool enabled = true;
    virtual const char* name() const = 0;
    virtual Phase phase() const;           // Phase::Init / Update / Render
    virtual int priority() const;          // 排序优先级
    virtual void on_init(Scene&);
    virtual void on_update(Scene&, float dt);
    virtual void on_render(Scene&, RenderContext&);
    virtual void on_shutdown(Scene&);
};
```

### 2.3 ComponentStore：`core/ecs/component_store.h` / `.cpp`

组件存储池，按组件类型哈希索引，每个类型存储在一个 `std::vector` 中，配合 `Entity` 的位掩码快速查询。

### 2.4 内置系统注册位置

| 系统 | 注册位置 | 所在 DLL |
|------|---------|---------|
| `AnimatorSystem` | `GCore_Init` | GryceCore |
| `FractureSystem` | `GCore_Init` | GryceCore |

## 3. 场景与实体系统

### 3.1 Scene：`core/scene/scene.h` / `scene.cpp`

- `Scene` 持有合成根节点 `root_`（不可销毁、不参与序列化）
- 组件存储池 `component_store_` 与场景绑定
- 支持子场景流送（`stream_in` / `stream_out`）
- 差异保存（`serialize_delta` / `save_delta`）
- 场景热重载（`hot_reload`：按 UUID 匹配更新现有实体）

### 3.2 Entity：`core/scene/entity.h` / `entity.cpp`

- `Entity` 是节点树节点，包含名字、UUID、子节点列表、组件位掩码
- 每个实体自动拥有 `Transform` 组件
- 查询：`find_child`、`find_descendant`、`foreach`

### 3.3 场景序列化：`core/scene/scene_serializer.h` / `.cpp`

- `.gesc` JSON 格式（版本 2，兼容 v1）
- `res:/` 虚拟路径
- `Prefab / Prefab Variant` 支持

### 3.4 实体句柄映射：`core/runtime/entity_handle_map.h` / `.cpp`

- `EntityHandleMap`：`int` 句柄 ↔ `UUID` 双向映射
- 句柄分配：从 1 开始递增，复用已释放的句柄
- 场景加载/新建后重建映射表

## 4. 组件系统

### 4.1 组件基类：`core/components/component.h`

所有组件继承自 `Component`，提供：
- `type()` — 返回类型名
- `serialize(json)` / `deserialize(json)` — JSON 序列化
- `clone()` — 克隆
- `on_add_to_entity()` / `on_remove_from_entity()` — 生命周期回调

### 4.2 组件工厂：`core/components/component_factory.h` / `.cpp`

- `ComponentFactory`：按名称注册/创建组件
- 编辑器 "Add Component" 对话框数据源
- `GCore_Init` 时注册全部组件

### 4.3 反射系统：`core/reflection/reflection.h` / `.cpp`

- `reflection::Registry`：组件字段反射
- 字段信息：名称、类型、读写回调、只读标记
- `builtin_reflections.cpp`：注册所有内置组件的反射
- 编辑器 Inspector 面板通过反射动态读写组件属性

### 4.4 组件注册清单

**3D 渲染**：`MeshRenderer`、`SkinnedMeshRenderer`、`Camera`、`Light`、`SubViewport`
**2D 渲染**：`Node2D`、`Node3D`、`ColorRect`、`Circle`、`Polygon`、`Label`、`Sprite2D`、`Tilemap`、`Camera2D`、`ParallaxBackground`、`ParticleEmitter2D`、`Light2D`、`AmbientLight2D`、`Skybox2D`
**3D 物理**：`StaticBody`、`RigidBody`、`BoxCollider`、`SphereCollider`、`PlaneCollider`、`CharacterController3D`、`Joint3D`、`DestructibleBody`、`FragmentBody`
**2D 物理**：`StaticBody2D`、`RigidBody2D`、`BoxCollider2D`、`CircleCollider2D`、`CharacterController2D`、`Joint2D`
**音频**：`AudioSource`、`AudioListener`
**其他**：`Terrain`、`Transform`（自动）、`PrefabInstance`、`PhysicsBody`、`PhysicalMaterial`

## 5. 渲染系统

### 5.1 渲染抽象层

**RenderContext**（`core/render/render_context.h`）：
- 高层渲染上下文，组合 `IRenderBackend` + `RenderCommandBuffer` + `RenderThread`
- 同步模式（编辑器）和异步模式（独立 demo）
- 资源创建/销毁、命令提交、帧控制

**IRenderBackend 接口**（`core/render/render.h`）：
- 后端无关的抽象接口
- 实现：`GLBackend`（`render/opengl/gl_backend.cpp`）和 `VKBackend`（`render/vulkan/vk_backend.cpp`）

### 5.2 渲染管线

**RenderPipeline**（`core/render/render_pipeline.h` / `.cpp`）：
- 3D 场景管线：PBR 正向渲染
- 阴影：CSM 级联阴影（1-4 级），PCF 软阴影，PCSS
- 后处理：HDR → Bloom → Tonemapping → 调色 → 镜头效果
- IBL：环境光照、天空盒
- TAA、GTAO、接触阴影

**RenderSystem3D**（`core/ecs/systems/render_system_3d.cpp`，GryceRenderer 中）：
- 收集场景中的 MeshRenderer 和 SkinnedMeshRenderer
- 按材质/网格排序，提交到渲染管线

**Renderer2D**（`core/render/renderer2d_impl.h` / `.cpp`，GryceRenderer 中）：
- 2D 批处理渲染器
- 支持：矩形、纹理、文字、圆形、多边形、光照、阴影

### 5.3 着色器

- 公共着色器位于 `examples/common/shaders/`
- GL 着色器：`.vert` + `.frag`
- Vulkan 着色器：`vulkan_*.vert` + `vulkan_*.frag`（编译为 SPIR-V）
- 编译规则在 `cmake/shaders.cmake`

### 5.4 渲染线程

`core/render/render_thread.h` / `.cpp`：
- 编辑器同步模式：渲染命令在主线程执行，`present_swap()` 在互斥锁外执行
- 异步模式：内部启动渲染线程，主线程通过命令队列提交绘制

## 9. Lua 脚本系统（GryceSRT）

### 9.1 实现位置

- `core/script/lua_runtime.h` / `.cpp`：Lua 运行时（状态管理、沙箱、API 绑定）
- `core/script/lua_math_bindings.h` / `.cpp`：数学绑定
- `core/script/big_number.h` / `.cpp`：大数支持
- `core/ecs/systems/script_system.h` / `.cpp`：脚本驱动系统
- `core/components/script_component.h`：脚本组件

### 9.2 ScriptComponent 字段

| 字段 | 说明 |
|------|------|
| `script_path` | `.lua` 文件路径 |
| `process_priority` | 更新优先级（值越大越先执行） |
| `pause_mode` | 暂停时是否继续执行 |
| `signals` | 信号连接表（`engine.signal.connect`） |
| `env_ref` | Lua registry 环境表引用 |
| `chunk_ref` | Lua registry 加载块引用 |
| `props` | 暴露的脚本属性（可序列化） |

### 9.3 ScriptSystem 驱动

- `on_update`：按优先级排序实体，调用 `on_start`（首次）和 `on_update(dt)`
- `_input(type, a, b, c)`：每帧更新前分发输入事件
- `engine.signal.connect(name, target, cb)` / `emit(name, ...)`：实体间通信

### 9.4 Lua 暴露的 API

| 命名空间 | 功能 |
|----------|------|
| `engine.time` | `dt`, `time` |
| `engine.transform` | `get_position`, `set_position`, `get_rotation`, `set_rotation`, `get_scale`, `set_scale` |
| `engine.physics` | `set_gravity`, `add_force`, `add_impulse` |
| `engine.audio` | `play`, `stop`, `set_volume`, `set_looping` |
| `engine.input` | `KEY_DOWN`, `KEY_UP`, `MOUSE_MOVE`, `MOUSE_DOWN`, `MOUSE_UP`, `is_key_pressed`, `is_key_held`, `get_mouse_position`, `mouse_locked` |
| `engine.signal` | `connect`, `emit` |
| `engine.entity` | `find_by_name`, `get_name` |
| `engine.scene` | `load`, `reload` |
| `engine.math` | `Vector2`, `Vector3`, `lerp`, `clamp` |

## 14. 数学库与数据结构

### 基础类型（`core/GryceCore/types.h`）

```c
typedef int   GEntityHandle;    // 实体句柄
typedef int   GAssetHandle;      // 资源句柄
typedef void* GTextureHandle;    // 纹理句柄
typedef void* GWindowHandle;     // 窗口句柄
typedef int   GBodyHandle;       // 物理刚体句柄
typedef struct { float x, y, z; }   GVec3;
typedef struct { float x, y, z, w; } GVec4;
typedef struct { float x, y, z, w; } GQuat;
typedef struct { float m[16]; }       GMat4;
typedef struct { float r, g, b, a; }  GColor;
```

### 命令结构

```c
typedef struct {
    GCommandType type;             // 命令类型枚举
    uint64_t     seq;              // 序号
    uint8_t      payload[256];     // 载荷（按命令类型不同）
} GCommand;
```

双缓冲队列，每缓冲容量 8192 条，每帧最多消费 30 条。
