# 文件名：script_vm.cpp

## 文件作用

这个文件是干什么的：它实现了 ScriptVM 这条"跑 JavaScript 的机器"。它是建立在 QuickJS 之上的，负责开启和关闭 JS 运行环境、执行一段 JS 代码，或者在模块模式下运行代码并拿到导出的东西。它还支持把 JS 源码先编译成一段字节码、再加载字节码来运行，方便提前打包脚本。为了模拟模块语法，它里面有一个把 export 改成用 exports 对象赋值的转换小工具，并且把 console.log 等转到引擎的日志里。它能把 C++ 传进来的参数转成 JS 值、把运行结果转成英文结果，还能读取和整理出错的信息。
