# 文件名：big_number.cpp

## 文件作用

这个文件是干什么的：它实现了两种能算超大数字的工具，一种叫 BigInt（算特别大的整数），一种叫 BigDecimal（算很多位小数的数），主要给刹车片的"big 模块"用，用来做普通 double 类型算不动的精确运算。BigInt 里面的每个数字用数组存起来，分成十进制的"位"，自己实现了加、减、乘、除、取余、乘方，还有比较大小、转成字符串这些操作。BigDecimal 则是用一个 BigInt 再加上记录小数点的位数（scale）来表示，里面实现了带小数位数的加减乘除、乘方、开方、四舍五入、floor/ceil 这些常见运算。
