# 文件名：system.h

## 文件作用

这个文件是干什么的：头文件，声明了所有系统（System）都要继承的基类 ISystem。它规定每个系统要叫自己什么名字、在哪个阶段运行（早期、主要、后期逻辑，以及渲染前、渲染、渲染后），以及优先级是多少。系统通过 on_init、on_shutdown、on_update、on_render 这几个在特定时刻会被调用的方法，来接入完整的运行流程。

它还提供了一个通用的重力开关（默认不做事，由 2D/3D 物理系统去自己实现），并允许每个系统说明自己关心哪些组件。这样各个系统就能按照统一的规矩加入游戏流程，方便 World 统一调度。
