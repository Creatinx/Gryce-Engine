# 文件名：physics_system_3d.cpp

## 文件作用

这个文件是干什么的：实现 PhysicsSystem3D 的具体工作。它创建并把控一个 3D 物理世界，每帧找出所有需要模拟的实体，为它们创建物理物体，根据组件算出各种碰撞体的形状（盒子、球、平面、胶囊、圆柱、凸包、网格、触发区等）挂上去。碰撞体或质量材质变了就会重建物体，保证模拟正确。

模拟时用固定小步长一步一步推进，支持 3D 角色的移动、跳跃、上下台阶、爬坡，把物理算出的位置速度写回组件，还负责创建和删除连接物体的关节、处理 3D 射线组件的结果，并把本帧的碰撞/触发事件取回来供别处使用。场景切换时会清理所有物理资源。
