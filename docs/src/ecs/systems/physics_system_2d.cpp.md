# 文件名：physics_system_2d.cpp

## 文件作用

这个文件是干什么的：实现 PhysicsSystem2D 的具体工作。它创建并把控一个 2D 物理世界，每帧找出场景里所有需要模拟的实体，为它们创建物理物体，把各类 2D 碰撞体（盒子、圆、多边形、胶囊、边缘、瓦片地图、区域）换算成物理形状挂到物体上。它会检测碰撞体和位置有没有变化，有变化就及时更新或重建。

模拟时它用固定小步长一步一步推进物理世界，支持角色的移动、跳跃、上下台阶、爬坡，也会把物理算出的位置和速度写回游戏组件。还负责创建和删除把两个物体连起来的关节、处理射线组件的结果，以及在场景切换时清理掉所有物理资源。
