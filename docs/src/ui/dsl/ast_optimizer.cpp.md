# 文件名：ast_optimizer.cpp

## 文件作用

这个文件是干什么的：把搭好的语法树（AST）进行一番整理和瘦身，让树更好用、更干净。它把界面里通过 class 或 style 引用的样式块，展开成控件自己身上的具体属性（如果控件自己已经写了某个属性，就保留控件自己的，不被样式盖掉），然后把这些写法的样式引用去掉。它还会把没有属性也没有子控件、等于摆设的空控件从树里删掉。

里面主要有一个 ASTOptimizer 类。它负责记住已经登记过的样式块，并按顺序处理每一个控件：先做常量整理（目前是空操作）、把样式属性展开合并进来、去掉重复属性，然后递归处理子控件，最后清掉那些没用的空控件。在树的顶层也会做同样的清理，去掉没有任何内容的空控件。
