# 文件名：semantic_analyzer.cpp

## 文件作用

这个文件是干什么的：检查搭好的语法树（AST）里的"意思"对不对，也就是做语义检查。它会对照一份内置的控件清单（如 Window、Text、Button、Slider 等十几种），核对每个控件是不是登记过的、它带的属性是不是名字合法、属性值的类型对不对（比如宽高应该是数字、勾选状态应该是真或假）。它还会检查必填属性有没有漏掉，比如按钮必须有文字、图片必须有来源。

里面主要有一个 SemanticAnalyzer 类。它内部记住了每种控件允许哪些属性和哪些必填项，逐个访问树里每一个控件做核对。起错控件名或属性名时，它还能通过比较相近程度给出"你是不是想写某某"的建议。出现任何问题都会记成一条条语义错误存下来，最后告诉调用方检查有没有通过。
