# 文件名：parser.cpp

## 文件作用

这个文件是干什么的：把前面拆好的一串"词"（token）按照界面语言的语法规则，搭成一颗有层级的结构树，也就是语法树（AST）。它能认识一个控件的完整写法：先是控件类型的名字，然后是括号里的一组属性（名字=值），还可以跟着一个大括号，里面再套更小的子控件，一层一层往下。

里面主要有两类内容：一条语法错误的记录（存了出错的行列、信息、给的提示），以及做这个语法分析的 Parser 类。Parser 会按规则依次读词、检查括号和等号是否齐全、把属性和子控件装进树里，碰到写错的地方会记下错误并跳到下一个能接着读的位置继续分析，尽量把剩下没写错的部分也分析出来。它还支持把值分成普通值和数组（中括号）两类。
