# 文件名：lexer.cpp

## 文件作用

这个文件是干什么的：把 UI 界面描述（.uif）的原始文字拆成一个个有意义的片段，这些片段叫"词"（token）。比如能认出控件名字、字符串、数字、真/假、各种括号和等号逗号。它会跳过空格和注释，还给每个词记下所在的行号和列号，方便后面报错时定位。遇到写错的地方（比如字符串没关、数字后面跟着字母、用了不认识的符号），它会记下错误信息并给出提示，然后继续往下读。

里面主要有三类内容：一是"词"的说明（每个词是什么类型、怎样转成文字），二是一条词法错误的记录（存了在哪行哪列、什么错、有什么提示），三是真正做扫描的 Lexer 类，负责一个字符一个字符地往后读、拼出完整的词并发现错误。
