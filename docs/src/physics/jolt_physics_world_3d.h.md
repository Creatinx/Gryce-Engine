# 文件名：jolt_physics_world_3d.h

## 文件作用

这个文件声明了使用 Jolt 物理引擎（5.x 版）做出来的 3D 物理世界类，名字叫 JoltPhysicsWorld3D，它是通用 3D 物理接口 IPhysicsWorld3D 的一个具体实现。声明里列出了这个类要实现的所有功能，包括初始化、推进、改变重力、创建和删除刚体、设位置速度、加力加推力、创建形状和关节、做射线检测、取回碰撞事件和冲量、遍历所有刚体等。文件里也记下了它内部要用到的 Jolt 各部分（如内存分配器、线程池、物理系统、接触监听器）和存放刚体、形状、关节的容器。整个文件包在"是否支持 Jolt"的功能开关里，没编 Jolt 就不进来。
