# 文件名：physics_types.h

## 文件作用

这个文件定义了物理系统里大家一起用的各种公共类型。它把刚体、形状、关节各用一个数字编号（句柄）来代表，还定下了一个"无效"编号表示东西不存在。这里列了刚体分几种（静止、可以推动的、完全动态的）、形状有哪几种（盒子、球、胶囊、圆柱、平面、凸包、三角网格），以及每个形状和刚体要带哪些参数（大小、偏移、转向、质量、速度等）。另外还定义了碰撞事件是怎么回事（开始接触、结束接触）、发生接触时把信息记下来的记录（CollisionEvent）、材质参数（摩擦、弹性、密度）、射线命中的结果（RaycastHit），以及 2D 和 3D 关节要用的各种参数。
