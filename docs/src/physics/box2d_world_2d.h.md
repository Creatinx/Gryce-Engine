# 文件名：box2d_world_2d.h

## 文件作用

这个文件声明了使用 Box2D 引擎（3 版）做出来的 2D 物理世界类，名字叫 Box2DPhysicsWorld2D，它是通用 2D 物理接口 IPhysicsWorld2D 的一个具体实现。声明里列出了这个类要实现的功能，包括初始化、推进、设重力、创建和删除刚体、改位置和速度、加力加推力、给刚体加盒子/圆形/胶囊/多边形/线段等形状、做射线检测、创建和删除关节。内部它用一个编号管理刚体、形状和关节的位置，并通过代际号防止"过期的编号误用到新对象"。整个文件包在"是否支持 Box2D"的功能开关里，没编 Box2D 就不进来。
