# 文件名：physics_world_2d.h

## 文件作用

这个文件声明了 2D 物理世界的通用接口（叫 IPhysicsWorld2D）。它定下了"一个 2D 物理世界应该能做什么"的清单，比如初始化、每帧往前推进、改变重力、创建和删除刚体、给刚体改位置和速度、加力加推力、给刚体加上盒子/圆形/胶囊/多边形/线段等形状、做射线检测、创建关节。具体怎么做它不管，由底下不同的物理引擎去实现。文件里还定义了一个 2D 射线检测结果的记录（RaycastHit2D），并声明了制造 2D 物理世界的函数（create_physics_world_2d），按名字返回一个具体的物理世界对象。
