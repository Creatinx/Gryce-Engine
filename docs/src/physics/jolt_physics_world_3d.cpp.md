# 文件名：jolt_physics_world_3d.cpp

## 文件作用

这个文件真正把 Jolt 物理引擎（3D）接进游戏，"动手"实现 jolt_physics_world_3d.h 里声明的每一件事。它负责把 Jolt 启动起来（初始化、配线程池、设重力），把引擎每帧往前推进，创建和删除刚体、给刚体改位置和速度、加力加推力、设置摩擦弹性；还能照着参数造出盒子、球、胶囊、圆柱、平面、凸包、三角网格等各种形状并接到刚体上；做射线检测、创建和删除关节（距离、弹簧、固定、铰链）。文件里还专门做了一个接触监听器，把 Jolt 里的碰撞和触发器接触转成自己的事件，并统计每个刚体最大的碰撞冲量，供碎裂等效果使用。所有代码都包在"是否支持 Jolt"的功能开关里。
